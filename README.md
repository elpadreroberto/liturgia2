# Liturgia 2026

Página pública: https://elpadreroberto.github.io/liturgia2/

`index.html` reúne Laudes, Vísperas y Oficio de octubre y noviembre de 2026, hasta el día 30, y la Misa de octubre a diciembre. El botón de las líneas alterna el español, el latín y, en el Nuevo Testamento, el griego: uno bajo el otro, en columnas en cualquier pantalla, y también el español junto al griego donde hay griego. Bajo cada evangelio está la Catena Aurea de Santo Tomás de Aquino.

`catena-aurea.json` guarda la fecha, la cita bíblica y esos comentarios.
