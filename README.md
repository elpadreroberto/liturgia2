# Liturgia 2026

Página pública: https://elpadreroberto.github.io/liturgia2/

`index.html` reúne Laudes, Vísperas, Oficio y la Misa de octubre a diciembre de 2026. Bajo cada evangelio está la Catena Aurea de Santo Tomás de Aquino.

`catena-aurea.json` guarda la fecha, la cita bíblica y esos comentarios.
